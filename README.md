# ArtistPro Score Library: String Quartets

A collection of string quartet scores and associated research data, hosted by ArtistPro.

## Using the files

Browse the `scores/` or `data/` directories. Editable MusicXML files use the `.mxl` extension; related notation, metadata and research files remain available in their original formats.

These files are hosted by ArtistPro for use with apScore. Import results may need review, especially complex notation and playback markings.
